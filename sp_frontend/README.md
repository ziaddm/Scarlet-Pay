# Scarlet Pay - Frontend

![version](https://img.shields.io/badge/version-1.0.0-blue.svg)

Scarlet Pay is a modern payment platform built with React and Material-UI. This frontend application provides a seamless user experience for managing payments, transactions, and financial operations.

## Features

- Modern, responsive UI built with React 18
- Material-UI components for consistent design
- Secure payment processing interface
- User-friendly dashboard
- Transaction management
- Real-time updates

## Tech Stack

- **React** 18.3.1 - Modern UI library
- **Material-UI** 5.16.7 - Component library
- **React Router** 6.26.1 - Navigation
- **Axios** - HTTP client
- **Recharts** - Data visualization
- **TypeScript Support** - Type safety

## Quick Start

### Prerequisites

- Node.js LTS version (Download from [NodeJs Official Page](https://nodejs.org/en/download/))
- npm or yarn package manager

### Installation

1. Navigate to the frontend directory:

```bash
cd sp_frontend
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm start
# or
yarn start
```

The application will open at [http://localhost:3000](http://localhost:3000)

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Runs the test suite
- `npm run lint` - Lints the codebase
- `npm run prettify` - Formats code with Prettier
